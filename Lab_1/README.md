Лабораторная работа №1 Работа посвящена анализу данных клиентов банка и построению модели машинного обучения для прогнозирования оформления срочного банковского депозита. Выполнялась предварительная обработка данных, анализ признаков, подготовка обучающей и тестовой выборок, обучение модели классификации и оценка её качества Использовался датасет bank.csv, который содержит информацию о клиентах банка, их социально-демографических характеристиках, финансовом положении и взаимодействии с банковскими услугами. Датасет включает в себя: age, job, marital, education, balance, housing, loan, contact, month, duration, campaign, pdays, previous, poutcome, deposit Переменная deposit показывает оформил ли клиент срочный депозит: yes-оформил депозит, no-не оформил депозит. Признак day исключается из анализа Бизнес-задача: разработать модель машинного обучения, которая на основе характеристик клиента и информации о предыдущих контактах прогнозирует вероятность оформления срочного депозита Для решения задачи используется алгоритм Random Forest. Качество модели оценивается на тестовой выборке с помощью метрики Accuracy В итоге был изучен датасет банковских клиентов, выполнена подготовка данных и преобразование категориальных признаков. Данные были разделены на обучающую и тестовую выборки с сохранением соотношения классов целевой переменной
