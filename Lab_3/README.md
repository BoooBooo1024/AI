Лабораторная работа №3 Метрики качества, кросс-валидация и пайплайны
Описание проета: Работа посвящена анализу данных медицинского страхования и построению моделей машинного обучения для решения двух задач: классификации курящих клиентов и прогнозирования медицинских расходов. 
Описание датасета: Использовался датасет insurance.csv, который содержит информацию о клиентах страховой компании, их социально-демографических характеристиках, образе жизни и медицинских расходах. Датасет включает в себя: age, sex, bmi, children, smoker, region, charges. Переменная smoker показывает, курит ли клиент (yes — курит, no — не курит) и используется как целевая переменная для задачи классификации. Переменная charges показывает медицинские расходы клиента в долларах и используется как целевая переменная для задачи регрессии. Баланс классов в задаче классификации составляет примерно 79.5% некурящих и 20.5% курящих. 
Бизнес-задача: разработать модели машинного обучения, которые на основе характеристик клиента позволяют, во-первых, определять курящих клиентов для задач underwriting и сегментации портфеля, а во-вторых, прогнозировать ожидаемые медицинские расходы для ценообразования и оценки рисков. Для решения задачи классификации используется алгоритм KNN с подбором гиперпараметров через GridSearchCV и стратифицированную кросс-валидацию, для задачи регрессии — KNN-регрессия с подбором гиперпараметров через RandomizedSearchCV. Качество моделей оценивалось на тестовой выборке с помощью метрик ROC-AUC, precision, recall, F1 для классификации и MAE, RMSE, SMAPE для регрессии.
Аналитический вывод: В итоге был изучен датасет медицинского страхования, выполнена подготовка данных и построение полноценных пайплайнов предобработки. Данные были разделены на обучающую и тестовую выборки со стратификацией по целевому классу для сохранения пропорций. В ходе анализа для задачи классификации лучшие параметры — k=3, weights='uniform', при этом accuracy составила 74%, однако ROC-AUC оказался всего 0.4939, precision по курящим 0.23 и recall 0.11, то есть модель пропускает 89% курильщиков из-за сильного дисбаланса классов. Для задачи регрессии лучшие параметры — k=27, weights='uniform', MAE составила $9 115, RMSE $11 623 и SMAPE 72.6%, а гистограмма остатков показала систематическое занижение дорогих случаев. Результаты работы позволяют оценить возможность применения машинного обучения в страховании: модель регрессии применима как сегментатор риска, но не для точной тарификации, а модель классификации требует перехода на более мощные алгоритмы и добавления новых признаков для практического внедрения в underwriting. Для более полной оценки качества моделей необходимо учитывать бизнес-метрики — стоимость пропущенных курильщиков и риск занижения премии по дорогим клиентам.
